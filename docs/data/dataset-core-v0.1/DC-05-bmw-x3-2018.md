## 7. Fricciones con el catálogo

| # | Tipo | Descripción | Propuesta |
|---|---|---|---|
| F1 | Granularidad / ciclo | **Un mismo `model_year` 2018 tiene dos homologaciones**: hasta 08/2018 NEDC + "EU6"; desde 09/2018 NEDC-correlated + EU6d-TEMP, con cambios también en depósito (60→68 L) y remolque (2000→2400 kg). `model_year` no basta para identificar el valor. | Añadir `valid_from`/`valid_to` (fecha de producción o matriculación) a nivel de Reference Variant o de SourcedValue, y permitir 2 variants por MY |
| F2 | Tipo de valor | Consumo y CO₂ oficiales publicados como **rango** por tamaño de neumático (5,4–5,0; 142–132); el UK los desglosa por "wheel cluster". El catálogo espera un decimal. | `SourcedValue` con `min`/`max` o clave de configuración (llanta) + regla para elegir el valor base |
| F3 | Conflicto de fuente | Documento ES 06/2017 con urbano/extraurbano incoherentes con el combinado y distintos del UK. | El pipeline de conflictos debe detectar incoherencia interna (urbano < combinado en ICE) |
| F4 | Método de maletero | La fuente ES no declara método (VDA/SAE); la UK usa códigos "V211-2 / V214-1". El catálogo exige método. | Estado `method_unknown`; tabla de equivalencias de códigos de método (Q3) |
| F5 | Enum de emisiones | "EU6" sin subnivel (6b/6c) en la fuente; el enum no tiene `Euro6` genérico. | Añadir `Euro6` (sin subnivel) |
| F6 | Masa | La fuente da DIN y UE (1750/1825). El catálogo pide "indicar norma" en notas, pero no hay campo. | Campo `mass_standard` (`DIN`/`EU`) o dos claves |
| F7 | DGT | Etiqueta solo derivable por regla (combustible + Euro); la DGT la da por matrícula. | Confirmar Q4: CALCULATED con regla versionada |
